# 为什么你宁愿信AI也不信自己

## 南宁新手妈妈豆包育儿事件

最近南宁一对新手爸妈，满月宝宝每顿只喂60ml奶，喂了一周。

孩子哭，他们没加量。老人劝，他们没改。因为他们问了豆包，豆包说60ml，他们就照做了。

一周后去南宁市妇幼保健院复查黄疸，医生发现不对劲——满月宝宝单次奶量通常在80到100ml，60ml偏低，孩子根本没吃饱。哭闹就是信号，但这对爸妈没接住。

这件事上了热搜，评论区一片骂AI。

骂得有道理吗？有道理。AI给了一个偏低的数据，新手爸妈照做了，孩子没吃饱。AI是起点，这没问题。

但如果你只骂到这一层，你就错过了真正重要的东西。

豆包的60ml不是胡说八道——早产儿或低体重儿确实可能每顿60到90ml。豆包也发了情况说明，称该描述“不实”，正常情况下不会给出这样的单一建议，通常会给出每日总奶量范围并提示关注婴儿反应。但家属也没有提供完整的对话记录，谁也不知道当时到底问了什么、AI到底回了什么。

所以问题不在于AI给了什么答案，而在于这对爸妈拿到答案之后，做了什么。

他们没有参考，没有对照，没有观察孩子的反应。他们服从了。

这才是真正值得追问的事：为什么两个成年人，宁愿相信一个聊天机器人的数字，也不信身边老人的劝说、不信眼前孩子的哭声？

## 你不是在参考AI，你是在服从它

参考和服从，看起来很像，其实是两码事。

参考是：我拿到一个信息，拿它跟其他信息对比，再结合实际情况做判断。服从是：我拿到一个信息，它就是答案，不用再想了。

这对爸妈做的事，是典型的服从。证据很清楚——老人劝他们多喂，他们不听；孩子哭了一周，他们不改。如果他们是在参考，任何一个信号都足以让他们重新核实。但他们没有。因为豆包说了60ml，60ml就是标准，标准不需要验证。

这就是服从的特征：一旦认定了“权威”，所有矛盾信息都会被自动过滤掉。不是没看到，是看到了也不算数。

有意思的是，豆包的回应和缺失的对话记录，前面说过了。但这不重要——即使AI真的只说了60ml，一个正常运转的判断力也会在第二天、最迟第三天，对着哭闹的孩子产生怀疑——“是不是不够？”可他们的判断力没有运转。不是被AI关掉了，是自己停掉了。

## 听AI的，错了可以怪AI

那为什么停掉了？

因为服从AI有一个隐秘的好处：错了不用怪自己。

想想看，如果这对爸妈听了老人的话多喂奶，结果孩子吃撑了吐奶，谁的责任？自己的。如果听了AI的话只喂60ml，结果孩子没吃饱，谁的责任？AI的。至少他们心里会这么想——“我是按标准来的，标准错了，不是我的问题。”

这就是判断力外包的本质：不是获取信息，是转移责任。

人做决策是痛苦的。每一个“我决定”后面都跟着“我承担”。选错了要自责，要被质疑，要面对“都怪你”的眼神。这种不适感是真实的，也是人本能想逃的。

而AI恰好提供了一个完美的逃避通道：它有数据、有依据，在你不确定的时候，看起来比你的直觉靠谱得多。把决策交给它，你既不用承受选择时的纠结，也不用承担选错后的自责。多舒服。

但舒服是有代价的。你每把一次判断交出去，你的判断力就弱一分。判断力就像肌肉，长期不发力就会萎缩——想想那些用了几年导航的人，离开手机连东南西北都分不清了，不是他们笨，是那个能力太久没用，退化了。到最后，不是你选择相信AI，是你已经没有能力不信了。

## 不只是育儿，你到处都在外包判断力

这对爸妈的故事听起来极端，但这种事每天都在发生，只是赌注大小不同。

职场上，让AI写方案，拿到就直接交。方案好不好？不知道，反正AI写的，应该没问题。领导问为什么这么定，答不上来——因为那个“为什么”从来就没有经过你的脑子。出了问题呢？“AI给的方案不行。”你看，责任又出去了。

你上次不查AI自己选餐厅是什么时候？让AI推荐餐厅，选了就去——省掉了比较和取舍，也省掉了培养自己品味的机会。让AI总结一本书，看完摘要就当读过了——“打动”和“不同意”都需要你自己跟内容碰撞，而碰撞的前提是你真的读过。

这些场景有一个共同特征：表面上看是提效，实际上是回避。回避的是“我选错了”的不适感。

选餐厅怕踩雷，让AI选，踩了雷怪AI推荐不行；写方案怕被毙，让AI写，被毙了怪AI水平不够；学东西怕走弯路，让AI规划路径，走偏了怪AI不懂我。每一次，你都在用“AI的判断”替换“我的判断”，然后用“AI的问题”替换“我的责任”。

而AI的“半正确”让这一切显得无比合理。60ml不是胡说八道，AI推荐的餐厅确实也不差，AI写的方案也过得去——它没有错到让你警觉，也没有对到让你成长。它恰好停在“够用”那条线上，让你觉得没必要再自己想了。

这才是最危险的地方：不是AI给了你错误答案，而是AI给了你一个“差不多对”的答案，刚好够你心安理得地放弃思考。

## 判断力是肌肉，不用就萎缩

回到那对南宁爸妈。

他们不是坏人，不是蠢人，他们只是新手，焦虑，想找一个确定的标准来抓住。而AI恰好给了他们一个看起来确定的东西。

但焦虑不是把判断力交出去的理由。恰恰相反，越焦虑越需要判断力——因为你面对的问题越重要，越不能靠一个聊天机器人替你扛。

判断力这个东西，不是知识，不是技能，是一种习惯。它需要你反复做一件事：在拿到任何答案之后，停一下，然后问自己三个问题——

有没有矛盾信号？身边有没有人持不同意见？眼前的事实跟AI说的对得上吗？

有没有我自己的经验可以对照？我以前遇到过类似的事吗？我的直觉在说什么？

出了事我怪谁？如果答案是“怪AI”，那这个问题你就不该只问AI。

不需要你成为专家，不需要你什么都懂，只需要你过一遍这三关。

那对爸妈缺的不是育儿知识，是那一下停顿。60ml拿到手，如果停一下——“这个量够吗？孩子吃了什么反应？要不要再查查？”——整件事就不会发生。

AI时代最大的风险，不是AI犯错，而是人忘了怎么判断。

AI会越来越强，答案会越来越“差不多对”，你外包判断力的理由会越来越充分。但每外包一次，你就弱一分。等到真正需要你自己判断的那天——健康、事业、家庭——你会发现，那块肌肉已经使不上劲了。

所以下次AI给你一个答案，别急着照做。停一下，过三关。
